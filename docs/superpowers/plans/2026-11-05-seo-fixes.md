# SEO Fixes Implementation Plan (H1 keywords, Blog, French version)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the three SEO gaps: H1 lacking name/keywords, hreflang + French version, and multiple indexable URLs via a blog.

**Architecture:** Three independent deliverables sharing the existing design system (`.site-shell` classes, CSS variables). Blog is a static data file + two routes with `generateStaticParams`. French page is a self-contained translated mirror of `page.tsx` at `/fr`. hreflang + sitemap updates tie them together.

**Tech Stack:** Next.js 16 App Router, static export, Tailwind v4 (`sr-only` available), lucide-react.

**Spec:** Approved conversation plan (2026-11-05): (1) sr-only keyword line inside H1; (2) `/blog` index + `/blog/[slug]` with 3 first-person posts from project content, each with unique `generateMetadata`; (3) `/fr` full translation, hreflang `alternates.languages` en↔fr on both sides; all new URLs in `sitemap.xml`. Blog link added to home topbar.

## Global Constraints

- No new dependencies; static export compatible (`generateStaticParams` mandatory for `[slug]`).
- Reuse existing CSS variables/classes (`--black`, `--white`, `--line`, `.site-shell`, `.topbar`, `.monogram`, `.footer`, `.eyebrow`, `.button-dark`, `.text-link`, `.repo-card`).

## Review Focus

- Static export: every dynamic route must be prerendered — run `npm run build` and confirm no `/blog/[slug]` fallback warnings.
- hreflang correctness: every `alternates.languages` map must include exactly `en` and `fr` keys with absolute URLs.
- French content: dates/labels must be properly translated (not EN strings left in FR page).
